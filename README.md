## Before opening an issue

1. Confirm the MCP4Unreal and Unreal Engine versions.
2. Search existing issues and reproduce the problem with the smallest practical project or steps.
3. Use the [bug report](../../issues/new?template=bug_report.yml) or [feature request](../../issues/new?template=feature_request.yml) form.
4. Write in any language listed above. You do not need to translate your report into English.

## Include

- MCP4Unreal version and Unreal Engine version/build.
- Windows version and connection mode (Streamable HTTP or STDIO).
- Clear reproduction steps, expected behavior, and actual behavior.
- A short, redacted log excerpt only when it is relevant.

## Protect your data

Never publish authentication tokens, private prompts, unreleased project details, credentials, private endpoints, absolute project paths, minidumps, or an unreviewed support bundle. MCP4Unreal must never create a GitHub issue or upload a bundle automatically. Review all prefilled text and attachments before submitting.

For a security vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
