# Soporte de MCP4Unreal

Este es el repositorio público oficial de soporte de MCP4Unreal para la comunidad latinoamericana. [English](README.md)

## Antes de reportar un problema

1. Confirma las versiones de MCP4Unreal y Unreal Engine.
2. Revisa los reportes existentes y reduce la reproducción a la menor cantidad de pasos posible.
3. Usa el formulario de [reporte de error](../../issues/new?template=bug_report.yml) o [solicitud de función](../../issues/new?template=feature_request.yml).
4. Puedes escribir en español; no hace falta traducir tu reporte al inglés.

## Información necesaria

Incluye las versiones del plugin, Unreal Engine y Windows, el modo de conexión, los pasos para reproducir, el comportamiento esperado y lo que ocurrió. Agrega sólo un fragmento corto y censurado del log si ayuda al diagnóstico.

## Protege tu información

Nunca publiques tokens, prompts privados, datos de proyectos aún no publicados, credenciales, endpoints privados, rutas absolutas, minidumps ni bundles de soporte sin revisar. MCP4Unreal no debe crear issues ni subir bundles automáticamente. Revisa el texto precargado y los adjuntos antes de enviar.

Para vulnerabilidades de seguridad, sigue [SECURITY.md](SECURITY.md) y no uses un issue público.
