# Suporte do MCP4Unreal

Este é o repositório público oficial de suporte do MCP4Unreal. [English](README.md)

## Antes de abrir uma issue

1. Confirme as versões do MCP4Unreal e do Unreal Engine.
2. Pesquise as issues existentes e reduza a reprodução ao menor número de passos possível.
3. Use o formulário de [relato de bug](../../issues/new?template=bug_report.yml&language=Portugu%C3%AAs%20%28Brasil%29) ou [solicitação de recurso](../../issues/new?template=feature_request.yml&language=Portugu%C3%AAs%20%28Brasil%29).
4. Você pode escrever em português; não precisa traduzir o relato para inglês.

## Informações necessárias

Informe as versões do plugin, Unreal Engine e Windows, o modo de conexão, os passos de reprodução, o resultado esperado e o resultado real. Inclua somente um trecho curto e revisado do log quando for relevante.

## Proteja seus dados

Nunca publique tokens de autenticação, prompts privados, detalhes de projetos não lançados, credenciais, endpoints privados, caminhos absolutos, minidumps ou bundles de suporte não revisados. O MCP4Unreal não deve criar issues nem enviar bundles automaticamente. Revise todo texto pré-preenchido e anexo antes do envio.

Para vulnerabilidades de segurança, siga [SECURITY.md](SECURITY.md) em vez de abrir uma issue pública.
