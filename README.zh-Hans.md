# MCP4Unreal 支持

这是 MCP4Unreal 的官方公开支持仓库。[English](README.md)

## 创建 Issue 之前

1. 确认 MCP4Unreal 和 Unreal Engine 版本。
2. 搜索现有 Issue，并尽量用最少步骤复现问题。
3. 使用[错误报告](../../issues/new?template=bug_report.yml)或[功能请求](../../issues/new?template=feature_request.yml)表单。
4. 可以使用简体中文，无需翻译成英文。

## 应包含的信息

请提供插件、Unreal Engine 和 Windows 版本、连接方式、复现步骤、预期结果和实际结果。仅在必要时附上已删除敏感信息的简短日志片段。

## 保护数据

请勿公开身份验证令牌、私人提示词、未发布项目详情、凭据、私人端点、绝对路径、内存转储或未经审查的支持包。MCP4Unreal 不得自动创建 GitHub Issue 或自动上传支持包。提交前请检查所有预填文本和附件。

安全漏洞请按照 [SECURITY.md](SECURITY.md) 私下报告，不要创建公开 Issue。
