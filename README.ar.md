# دعم MCP4Unreal

هذا هو مستودع الدعم العام الرسمي لـ MCP4Unreal. [English](README.md)

## قبل فتح مشكلة

1. تحقق من إصدار MCP4Unreal وإصدار Unreal Engine.
2. ابحث في المشكلات الحالية وحاول إعادة المشكلة بأبسط خطوات ممكنة.
3. استخدم نموذج [تقرير خطأ](../../issues/new?template=bug_report.yml) أو [طلب ميزة](../../issues/new?template=feature_request.yml).
4. يمكنك الكتابة بالعربية؛ لا يلزم ترجمة التقرير إلى الإنجليزية.

## المعلومات المطلوبة

اذكر إصدار الإضافة وإصدار Unreal Engine وWindows وطريقة الاتصال، ثم خطوات إعادة المشكلة والنتيجة المتوقعة والنتيجة الفعلية. أرفق مقتطف سجل قصيراً ومنقحاً فقط عند الحاجة.

## حماية البيانات

لا تنشر رموز المصادقة أو التعليمات الخاصة أو بيانات المشاريع غير المنشورة أو بيانات الاعتماد أو نقاط النهاية الخاصة أو المسارات المطلقة أو ملفات التفريغ أو حزمة دعم لم تراجعها. يجب ألا ينشئ MCP4Unreal مشكلة GitHub أو يرفع حزمة تلقائياً. راجع كل النصوص والمرفقات قبل الإرسال.

للثغرات الأمنية اتبع [SECURITY.md](SECURITY.md) ولا تفتح مشكلة عامة.
