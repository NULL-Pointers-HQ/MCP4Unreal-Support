# Security Policy

Do not report a suspected vulnerability in a public issue.

Use GitHub's **Report a vulnerability** option for this repository when it is available. If private vulnerability reporting is unavailable, use the private contact channel listed on the MCP4Unreal Fab product page and avoid publishing technical details until a maintainer confirms a secure channel.

Never include authentication tokens, credentials, private prompts, private endpoints, unreleased project content, absolute local paths, minidumps, or unreviewed support bundles in a public report.

Ordinary crashes, setup problems, and feature requests that do not expose a security weakness belong in the public issue forms.
