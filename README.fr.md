# Assistance MCP4Unreal

Ceci est le dépôt public officiel d'assistance pour MCP4Unreal. [English](README.md)

## Avant d'ouvrir une issue

1. Vérifiez les versions de MCP4Unreal et d'Unreal Engine.
2. Recherchez les issues existantes et réduisez la reproduction au minimum.
3. Utilisez le formulaire de [rapport de bug](../../issues/new?template=bug_report.yml&language=Fran%C3%A7ais) ou de [demande de fonctionnalité](../../issues/new?template=feature_request.yml&language=Fran%C3%A7ais).
4. Vous pouvez écrire en français sans traduire votre rapport en anglais.

## Informations à fournir

Indiquez les versions du plugin, d'Unreal Engine et de Windows, le mode de connexion, les étapes de reproduction, le résultat attendu et le résultat observé. N'ajoutez qu'un court extrait de journal expurgé si nécessaire.

## Protection des données

Ne publiez jamais de jetons d'authentification, prompts privés, informations de projets non publiés, identifiants, endpoints privés, chemins absolus, minidumps ou bundles non vérifiés. MCP4Unreal ne doit jamais créer une issue ni téléverser un bundle automatiquement. Vérifiez tout texte prérempli et toute pièce jointe avant l'envoi.

Pour une vulnérabilité, suivez [SECURITY.md](SECURITY.md) au lieu d'ouvrir une issue publique.
