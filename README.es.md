# Soporte de MCP4Unreal

Este es el repositorio público oficial de soporte para MCP4Unreal. [English](README.md)

## Antes de abrir un issue

1. Confirma las versiones de MCP4Unreal y Unreal Engine.
2. Busca en los issues existentes e intenta reproducir el problema con los pasos mínimos.
3. Usa el formulario de [reporte de error](../../issues/new?template=bug_report.yml&language=Espa%C3%B1ol) o [solicitud de función](../../issues/new?template=feature_request.yml&language=Espa%C3%B1ol).
4. Puedes escribir en español; no necesitas traducir el reporte al inglés.

## Qué debes incluir

Indica las versiones del plugin, Unreal Engine y Windows, el modo de conexión, los pasos de reproducción, el resultado esperado y el resultado real. Incluye sólo un extracto breve y censurado del log cuando sea relevante.

## Protege tus datos

Nunca publiques tokens de autenticación, prompts privados, detalles de proyectos sin publicar, credenciales, endpoints privados, rutas absolutas, minidumps ni bundles de soporte sin revisar. MCP4Unreal nunca debe crear un issue ni subir un bundle automáticamente. Revisa todo el texto precargado y cada adjunto antes de enviarlos.

Para vulnerabilidades de seguridad, sigue [SECURITY.md](SECURITY.md) y no abras un issue público.
