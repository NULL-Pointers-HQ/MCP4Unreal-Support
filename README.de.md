# MCP4Unreal-Support

Dies ist das offizielle öffentliche Support-Repository für MCP4Unreal. [English](README.md)

## Vor dem Erstellen eines Issues

1. Prüfe die Versionen von MCP4Unreal und Unreal Engine.
2. Suche in vorhandenen Issues und reduziere die Reproduktion auf möglichst wenige Schritte.
3. Verwende das Formular für einen [Fehlerbericht](../../issues/new?template=bug_report.yml) oder einen [Funktionswunsch](../../issues/new?template=feature_request.yml).
4. Du kannst auf Deutsch schreiben; eine englische Übersetzung ist nicht erforderlich.

## Benötigte Angaben

Nenne Plugin-, Unreal-Engine- und Windows-Version, Verbindungsart, Reproduktionsschritte sowie erwartetes und tatsächliches Verhalten. Füge nur bei Bedarf einen kurzen, bereinigten Logauszug hinzu.

## Datenschutz

Veröffentliche niemals Authentifizierungs-Token, private Prompts, unveröffentlichte Projektdaten, Zugangsdaten, private Endpunkte, absolute Projektpfade, Minidumps oder ungeprüfte Support-Bundles. MCP4Unreal darf weder automatisch ein GitHub-Issue erstellen noch ein Bundle hochladen. Prüfe alle vorausgefüllten Texte und Anhänge vor dem Absenden.

Sicherheitslücken bitte gemäß [SECURITY.md](SECURITY.md) und nicht öffentlich melden.
