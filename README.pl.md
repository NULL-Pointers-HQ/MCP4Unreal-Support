# Pomoc MCP4Unreal

To oficjalne publiczne repozytorium pomocy dla MCP4Unreal. [English](README.md)

## Przed utworzeniem zgłoszenia

1. Sprawdź wersje MCP4Unreal i Unreal Engine.
2. Przeszukaj istniejące zgłoszenia i ogranicz reprodukcję do minimum.
3. Użyj formularza [zgłoszenia błędu](../../issues/new?template=bug_report.yml&language=Polski) lub [prośby o funkcję](../../issues/new?template=feature_request.yml&language=Polski).
4. Możesz pisać po polsku; tłumaczenie na angielski nie jest wymagane.

## Wymagane informacje

Podaj wersje pluginu, Unreal Engine i Windows, tryb połączenia, kroki reprodukcji oraz oczekiwany i rzeczywisty rezultat. Dołącz tylko krótki, zanonimizowany fragment logu, jeśli jest potrzebny.

## Ochrona danych

Nie publikuj tokenów, prywatnych promptów, danych nieopublikowanych projektów, poświadczeń, prywatnych endpointów, ścieżek bezwzględnych, minidumpów ani nieprzejrzanych pakietów wsparcia. MCP4Unreal nie może automatycznie tworzyć zgłoszeń ani przesyłać pakietów. Przejrzyj wstępnie wypełniony tekst i załączniki przed wysłaniem.

Luki bezpieczeństwa zgłaszaj według [SECURITY.md](SECURITY.md), a nie publicznie.
