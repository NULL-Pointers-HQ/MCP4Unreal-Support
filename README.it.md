# Supporto MCP4Unreal

Questo è il repository pubblico ufficiale di supporto per MCP4Unreal. [English](README.md)

## Prima di aprire una issue

1. Verifica le versioni di MCP4Unreal e Unreal Engine.
2. Cerca tra le issue esistenti e riduci la riproduzione ai passaggi minimi.
3. Usa il modulo per [segnalare un bug](../../issues/new?template=bug_report.yml) o [richiedere una funzionalità](../../issues/new?template=feature_request.yml).
4. Puoi scrivere in italiano; non serve tradurre il rapporto in inglese.

## Informazioni da includere

Indica le versioni del plugin, di Unreal Engine e di Windows, la modalità di connessione, i passaggi di riproduzione, il risultato previsto e quello effettivo. Includi solo un breve estratto di log oscurato quando necessario.

## Protezione dei dati

Non pubblicare token di autenticazione, prompt privati, dettagli di progetti non pubblicati, credenziali, endpoint privati, percorsi assoluti, minidump o bundle non esaminati. MCP4Unreal non deve creare issue o caricare bundle automaticamente. Controlla testo precompilato e allegati prima dell'invio.

Per vulnerabilità di sicurezza, segui [SECURITY.md](SECURITY.md) senza aprire una issue pubblica.
