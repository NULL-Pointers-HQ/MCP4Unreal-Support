# MCP4Unreal サポート

MCP4Unreal の公式公開サポートリポジトリです。[English](README.md)

## Issue を作成する前に

1. MCP4Unreal と Unreal Engine のバージョンを確認してください。
2. 既存の Issue を検索し、できるだけ少ない手順で問題を再現してください。
3. [バグ報告](../../issues/new?template=bug_report.yml)または[機能リクエスト](../../issues/new?template=feature_request.yml)フォームを使用してください。
4. 日本語で投稿できます。英語への翻訳は不要です。

## 記載する情報

プラグイン、Unreal Engine、Windows のバージョン、接続方式、再現手順、期待した結果、実際の結果を記載してください。必要な場合のみ、機密情報を除いた短いログを添付してください。

## データの保護

認証トークン、非公開プロンプト、未公開プロジェクト情報、認証情報、非公開エンドポイント、絶対パス、ミニダンプ、未確認のサポートバンドルを公開しないでください。MCP4Unreal が Issue を自動作成したり、バンドルを自動アップロードしたりしてはいけません。送信前に自動入力された文章と添付ファイルを確認してください。

脆弱性は公開 Issue ではなく [SECURITY.md](SECURITY.md) に従って報告してください。
